この検証の限界
  • 過去再現は「現在の上場銘柄」で計算しているため、上場廃止になった銘柄が含まれず成績がやや良く出ます（生存者バイアス）。
  • 過去再現に使うのは株価・出来高だけで決まる点数です（押し目スコアは業績維持20点を除く80点分、従来スコアはトレンド・需給・地合い）。業績・増配・TDnetの開示は過去データが無いため含みません。
  • ランキングの翌営業日の始値で買い、往復の売買コストを差し引いた計算です。ストップ高で買えない・約定が滑るといった実際のズレは含みません。
  • 期間が重なる計算のため、1か月後などの結果は独立した試行ではありません。数字は目安として見てください。
  • 過去の成績は将来の利益を保証しません。

【外部環境】とは

その銘柄の業種に関係する、米国株・為替・金利・原油などの直近の動きです（例：半導体ならSOX指数やNVIDIA、自動車ならTeslaやドル円、銀行なら米国の金利）。🟢追い風・🟡影響は小さめ・🔴逆風で表示します。 順位への影響はごく小さく（総合点で最大±2.5点、順位は上下3位まで）、押し目・業績・増配・自社株買いの評価が主役です。業種との対応はシステムが自動で決めるので、設定は不要です。

用語のかんたん解説
押し目
上昇トレンドの途中で、株価が一時的に下がって調整している状態。急騰した直後ではなく、落ち着いた位置にいる銘柄を探します。
50日線・200日線
過去50日・200日の平均株価の線。50日線が200日線より上なら長期の上昇トレンドです。
TDnet・下方修正
上場企業の適時開示（ニュース）。会社が業績予想を引き下げる「下方修正」は、株価が下がりやすい悪材料なので大きく減点します。
出来高
その日に売買された株数。普段より多いほど、注目や大きな資金が入っている可能性があります。
移動平均線（25日・75日）
過去の平均株価を線にしたもの。株価が線の上にあり、線自体も上向きなら上昇トレンドです。
黒字転換・最高益
赤字だった本業の利益が黒字になる／過去で一番大きな利益になること。
増配・連続増配
配当金を増やすこと／毎年増やし続けていること。株主を大事にする姿勢のサインです。
PF・シャープレシオ
PFは「総利益÷総損失」で1より大きいほど良い成績。シャープレシオは「リターン÷値動きの大きさ」で、大きいほど効率が良い指標です。
RSI / MACD
買われすぎ（RSI70〜80超）や勢いの変化を見る指標です。
