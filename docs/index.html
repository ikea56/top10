用語のかんたん解説
押し目
上昇トレンドの途中で、株価が一時的に下がって調整している状態。急騰した直後ではなく、落ち着いた位置にいる銘柄を探します。
50日線・200日線
過去50日・200日の平均株価の線。50日線が200日線より上なら長期の上昇トレンドです。
TDnet・下方修正
上場企業の適時開示（ニュース）。会社が業績予想を引き下げる「下方修正」は、株価が下がりやすい悪材料なので大きく減点します。
出来高
その日に売買された株数。普段より多いほど、注目や大きな資金が入っている可能性があります。
移動平均線（25日・75日）
過去の平均株価を線にしたもの。株価が線の上にあり、線自体も上向きなら上昇トレンドです。
黒字転換・最高益
赤字だった本業の利益が黒字になる／過去で一番大きな利益になること。
増配・連続増配
配当金を増やすこと／毎年増やし続けていること。株主を大事にする姿勢のサインです。
PF・シャープレシオ
PFは「総利益÷総損失」で1より大きいほど良い成績。シャープレシオは「リターン÷値動きの大きさ」で、大きいほど効率が良い指標です。
RSI / MACD
買われすぎ（RSI70〜80超）や勢いの変化を見る指標です。
