点数の見方（計算方法）

下の1〜7が「点数」、並び順は点数＋新着ボーナスです。

  2. 新しさ：2日以内は100％、15日前に向けて35％まで直線で下げる。
  3. 情報源の確からしさ：TDnet・JPX公式 100％、報道 70％、財務データ 60％を掛ける。
  4. 重大な語（隠蔽・逮捕・過去最大・大規模など）があれば +5点ずつ（最大+15点）。
  5. 複数の情報源が同じ種類のイベントを報じていれば、+10％ずつ（最大1.25倍）。
  6. 会社の点数：イベントの種類ごとに一番高い1件を取り、100 × (1 − Π(1 − 各点数/100)) で合成します（種類が重なるほど100に近づきますが、100は超えません）。
  7. 区分：重大 80以上／警戒 60以上／注意 40以上／それ未満は軽微。
