見方・注意

  • 時間帯の区切り（日本時間）：東京 09:00〜15:30／欧州 15:30〜22:00／NY 22:00〜翌06:00。各時間帯の「始値→終値」の動きを、その時間帯の参加者の買い・売りの結果として見ています。
  • スコア：直近20営業日の勝率・平均pips・期待値・累積損益・連続記録を総合した指数です（それぞれ普段の動きの大きさで割って比べているので、単純な勝率順ではありません）。大きいほど片方に偏っています。スコアが30未満は偶然の範囲で「中立」、30〜50は「やや優勢」、50〜70は「優勢」、70以上は「強い優勢」です（値動きがまったくの偶然でも、20日の短い期間では50以上が2割ほど出ます。数日のうちに入れ替わることもあります）。
  • 総合判定：3つの市場の指数を、各市場の普段の動きの大きさで重みづけして合算しています。
  • データ：Yahoo Finance（JPY=X）の1時間足。毎日の更新でためていくため、期間は日がたつほど長くなります（現在 2024-02-15〜2026-11-18、717営業日）。1時間足のため、15:30は前後の足を補間した価格で代用しています。
